# oscpm conformance corpus: pattern matching
#
# One case per line. Blank lines and lines beginning with '#' are ignored;
# a '##' line names the section that follows.
# A case has three fields:
#
#   "<pattern>" "<address>" <expected>
#
# The pattern and address are double-quoted so that a space inside either
# is visible and testable. Neither may contain a double quote. Everything
# after the second quoted field is whitespace-separated:
#
#   match
#   nomatch
#   malformed-pattern <Error> <offset>
#   malformed-address <Error> <offset> <match|nomatch>
#
# <Error> is the enumerator name from oscpm::Error and <offset> is the
# zero-based byte offset the library must report.
#
# A malformed-pattern case asserts that Pattern::parse fails with that kind
# and offset and that match() returns false. Only three kinds arise from a
# pattern: MissingLeadingSlash at 0; UnterminatedClass at the '[' that has no
# ']' before the next '/'; UnterminatedBraces at the '{' that has no '}'
# before the next '/'. Every other pattern parses. A byte that no address can
# contain, a '{' inside braces, an empty class, a stray closer or an empty
# part is a literal that matches nothing where it stands, and a list member
# containing one is a dead member that leaves the others live.
#
# A malformed-address case asserts that the pattern parses, that
# validateAddress reports that kind and offset, and that match() and
# Pattern::matches(), which compare bytes and never validate the address,
# return the trailing field. Address faults: MissingLeadingSlash at 0;
# TrailingSlash at the final '/' (a bare "/" is TrailingSlash at 0);
# EmptyPart at the second of two adjacent '/'; IllegalByte at the byte, for a
# byte outside 0x21..0x7E or one of ' #*,?[]{}'; PartTooLong at the first
# byte of a part beyond kMaxAddressPartLength.
#
# The first fault by byte offset wins. An unterminated '[' or '{' faults at
# its opening byte, so it is reported before anything inside it.
#
# A match or nomatch case asserts that the pattern parses, that the address
# validates, and that match() and Pattern::matches() agree on the result.
#
# Slashes are read lexically. A run of two or more adjacent slashes is one
# "//" operator wherever it occurs: leading, between parts, or trailing,
# where it matches the part before it and every descendant of it. A single
# trailing slash is a separator followed by an empty part. The pattern "/"
# is a leading separator with one empty part.
#
# The corpus is plain text so that other OSC implementations can reuse it.
## Exact match

"/a"                "/a"                match
"/synth/1/freq"     "/synth/1/freq"     match
"/a/b/c"            "/a/b/c"            match
"/-_.~!$%&'()+=@^`|""/-_.~!$%&'()+=@^`|"match

"/*//*"             "/a"                nomatch
"/*//*"             "/a/b/c/d"          match
"//*//*"            "/a/b"              match
"//*//*"            "/a"                nomatch
"/a*//*b"           "/ax/yb"            match
"/a*//*b"           "/ax/1/2/yb"        match
"/a*//*b"           "/ax/1/2/by"        nomatch

## "//" backtracks past a false first match of a wildcard part

"//a*/b"            "/ax/x/ay/b"        match
"//a*/b"            "/ax/x/ay/c"        nomatch
"//*x/y"            "/ax/z/bx/y"        match
"//*x/y"            "/ax/z/bx/z"        nomatch
"//{a,ab}/b"        "/ab/x/a/b"         match
"//{a,ab}/b"        "/ab/x/a/c"         nomatch
"//[a-c]/[x-z]"     "/a/b/c/z"          match
"//[a-c]/[x-z]"     "/a/b/c/w"          nomatch
"//?/*x"            "/ab/c/dx"          match
"//?/*x"            "/ab/cd/dx"         nomatch
"/*//?"             "/a/bc/d"           match
"/*//?"             "/a/bc/de"          nomatch

## A trailing run of slashes is the operator: the part before it and every descendant

"//"                "/a"                match
"/a//"              "/a"                match
"//a//"             "/a"                match
"/a/b//"            "/a/b"              match
"//a//b/"           "/a/b"              nomatch

## A run of three or more slashes is one operator

"///"               "/a"                match
"///a"              "/a"                match
"////a"             "/a"                match
"/a///b"            "/a/b"              match
"/a////b"           "/a/b"              match
"//a///b"           "/a/b"              match
"/a///"             "/a"                match

## The first fault by byte offset wins around "//"

"/a//["             "/a"                malformed-pattern UnterminatedClass 4
"/a///["            "/a"                malformed-pattern UnterminatedClass 5
"/[a//b]"           "/a"                malformed-pattern UnterminatedClass 1
"/{a//b}"           "/a"                malformed-pattern UnterminatedBraces 1
"/a]//b"            "/a/b"              nomatch
"//a//b#"           "/a/b"              nomatch

## Two slashes in an address are an empty part; matching still compares bytes

"//a"               "//a"               malformed-address EmptyPart 1 match
"/a//b"             "/a//b"             malformed-address EmptyPart 3 match
"//a"               "/"                 malformed-address TrailingSlash 0 nomatch

## Bare "//" is a leading run with nothing after it: zero or more parts, so every address
"//"                "/a"                match
"//"                "/a/b/c"            match
"///"               "/x/y"              match
## A trailing run of slashes matches the part before it and all its descendants
"/a//"              "/a"                match
"/a//"              "/a/b"              match
"/a//"              "/a/b/c"            match
"/a//"              "/b"                nomatch
"/a//"              "/ab"               nomatch
"//a//"             "/x/a/y"            match
"//a//"             "/a"                match
"//a//"             "/x/b"              nomatch
"/a/b//"            "/a/b/c/d"          match
"/a/b//"            "/a/c"              nomatch
## Nested '{' is literal: the first '}' closes, and the trailing '}' is a dead literal
"/{a,{b,c}}"        "/a"                nomatch
"/{a,{b,c}}"        "/c"                nomatch
"/{a,{b,c}}"        "/b"                nomatch
## A dead alternative leaves the live ones matching
"/{a*,b}"           "/b"                match
"/{a[b],c}"         "/c"                match
"/a{,x?}"           "/a"                match
