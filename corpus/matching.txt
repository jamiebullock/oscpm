# oscpm conformance corpus: pattern matching
#
# One case per line. Blank lines and lines beginning with '#' are ignored;
# a '##' line names the section that follows.
# A case has three fields:
#
#   "<pattern>" "<address>" <expected>
#
# The pattern and address are double-quoted so that a space inside either
# is visible and testable. Neither may contain a double quote. Everything
# after the second quoted field is whitespace-separated:
#
#   match
#   nomatch
#   malformed-pattern <ErrorKind> <offset>
#   malformed-address <ErrorKind> <offset>
#
# <ErrorKind> is the enumerator name from oscpm::ErrorKind and <offset> is
# the zero-based byte offset the library must report. Offsets point at the
# byte that made the input Malformed:
#
#   MissingLeadingSlash         0
#   BareRoot                    0
#   TrailingSlash               the final '/'
#   EmptyPart                   the '/' that closes the empty Part: the
#                               second of two adjacent '/' in an Address,
#                               or the third of three or more in a Pattern,
#                               where "//" is the Descendant Operator
#   IllegalCharacter            the offending byte
#   EmptyCharacterClass         the ']' that closes "[]" or "[!]"
#   UnterminatedCharacterClass  the '[' that is never closed in its Part
#   UnterminatedAlternative     the '{' that is never closed in its Part
#   NestedAlternative           the inner '{'
#   BracketInAlternative        the '[' or ']' inside the braces
#   PartTooLong                 the first byte of a Pattern Part beyond
#                               maxPatternPartLength; exercised in
#                               pattern_test.cpp rather than here, since the
#                               cases are thousands of bytes long
#
# The first fault by byte offset wins. An unterminated '[' or '{' faults at
# its opening byte, so it is reported before anything inside it; a
# terminated one is scanned for faults inside. When two rules fault at the
# same byte, the more specific is reported: in the Address "/a//" the second
# '/' both closes an empty Part and ends the input, and the empty Part is
# reported; a reserved byte that is also the first byte beyond
# maxPatternPartLength is IllegalCharacter, not PartTooLong.
#
# In a Pattern "//" is the Descendant Operator, permitted leading and
# between Parts. A Pattern ending in "//" is TrailingSlash at its final '/',
# and a run of three or more '/' is EmptyPart at the third, which both
# closes an empty Part and, in "///", ends the input.
#
# Within a Part, a ']', '}' or ',' outside the construct that gives it
# meaning is IllegalCharacter: no Address may contain it, so it could never
# match and is a fault rather than a literal.
#
# A malformed-pattern case asserts on Pattern::parse and match(). A
# malformed-address case asserts that the pattern parses, that
# validateAddress reports the kind and offset, and that matches() and
# match() report Malformed. A match or nomatch case asserts that both sides
# are well-formed and that matches() and match() agree on the result.
#
# The corpus is plain text so that other OSC implementations can reuse it.

## A trailing "//" is Malformed at its final '/'

"//"                "/a"                malformed-pattern TrailingSlash 1

"/a/b//"            "/a/b"              malformed-pattern TrailingSlash 5
"//a//b/"           "/a/b"              malformed-pattern TrailingSlash 6
